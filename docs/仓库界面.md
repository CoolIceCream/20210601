# 仓库界面（M15）

> 参考玩家给的两张仓库截图重排：5 列网格 + 底部详情卡 + 容量上限。

## 为什么要改

M13 的仓库是 3×3 九格，两条鱼就塞满视觉空间，而且格子里硬塞
「鱼名 / 阶段 / 成长 / 价格」四行，字挤在一起看不清。
参考游戏的做法更省地方：**格子里只留图和两个数字**，其余全搬到
下面一张固定高度的详情卡里，点谁就换谁。

## 版式

```
┌─ 仓库 ──────────────────────────── ✕ ┐
│ [商店][鱼卵][图鉴][鱼塘][仓库]        │  ← 大页签
│ [鱼卵] [道具] [鱼]          [繁育]    │  ← 子页签
│ 鱼篓 5/20 · 选中 1     [批量][全选]   │  ← 容量行
│ ┌──┬──┬──┬──┬──┐                     │
│ ├──┼──┼──┼──┼──┤  5 列网格            │
│ └──┴──┴──┴──┴──┘                     │
│ ┌──────────────────────────────┐     │
│ │[图] 名称 ♀            ¥ 6,850│     │  ← 详情卡
│ │     说明两行                  │     │
│ │     [词条][词条]              │     │
│ │     [ 放进鱼缸 ][ 卖出 ]      │     │
│ └──────────────────────────────┘     │
└──────────────────────────────────────┘
```

网格行数按屏高自适应：大屏 4 行 20 格，小屏退到 3 行 / 2 行，
格子高度跟着压缩，保证详情卡永远在屏幕内。

## 格子放什么

| 子页 | 图标 | 左下 | 右下 | 角标 |
| --- | --- | --- | --- | --- |
| 鱼 | 鱼缩略图（含进化阶） | 卖价 | 成长%（满级不标） | 左上性别、右上选中序号 |
| 道具 | 珍珠贝 / 珍珠 / 鱼饵 | 名称 | 数量 | — |
| 鱼卵 | 蛋 | 「待孵」/ 倒计时 | 性别 / 「在孵」 | 左上性别、右上选中序号 |

- 格子边框按稀有度上色（R 绿 / SR 金 / SSR 珊瑚），选中的格子换成金色粗框。
- 空格子只画一圈暗金细框，让网格看得出「还有多少格」。
- 成鱼不标成长百分比 —— 满级是常态，标了满屏都是 100%，反而看不出鱼苗。

## 交互

1. **点格子选中**：详情卡显示这一件的资料和按钮。
2. **再点同一格取消**；单选模式下点另一格是「换选」。
3. **批量**：开启后点格子是**加选**（显示选中序号 1、2、3…），
   详情卡变成「已选 N 条 + 合计金额」，按钮换成批量放缸 / 批量卖出。
4. **全选 / 清空**：只覆盖屏幕上看得见的格子，所见即所选。
5. **退出批量**会清空选择，避免下次进来还挂着一批看不见的选中。
6. 详情卡上的空白区域会吞掉点击，不会穿透成「点空白取消选中」。

## 容量上限

`config/economy.js` 的 `bagCap: 20`。鱼篓满了以后抛竿返回 `bag_full`，
提示「鱼篓满了 · 去仓库放缸或卖几条」。

## 鱼卵子页（M16 改）

这一页现在是**孵化台**，不再只是展示柜：

```
鱼卵 4/24 · 在孵 2/6 · 选中 1     [批量][全选]
┌────┬────┬────┬────┬────┐
│1:58│1:18│待孵│待孵│待孵│   ← 前两个带进度条（在孵），后面是仓库里的蛋
└────┴────┴────┴────┴────┘
[图] 桃花鲤的蛋 ♀
     孵 3:00 · 鱼苗直接进鱼篓
     带 1 条词条，孵出即成
     [ 孵化 · 占 1 个培育位 ]
```

- **格子顺序固定**：先「在孵」的（金边 + 进度条），再仓库里囤着的（暗金边 + 「待孵」）。
- **在孵的格子不可选中** —— 它已经在孵了，选中也没按钮可给。
- 选中一颗 → 详情卡「孵化」；批量选中 N 颗 → 「批量孵化 孵 N 颗 · 空位 M」。
- 装不下的蛋留在仓库（吐司提示「N 颗装不下」），不丢。
- 蛋的孵化时长在**产卵那一刻**就写进蛋里，所以亲本卖掉也不影响这颗蛋。
- 空页给引导：「还没有鱼卵 · 点右上「繁育」配一窝」。

- 上限判断在 `core/pond.js` 的 `bagCapOf()` / `isBagFull()`。
- `bagCapOf` 永远不小于当前条数，老存档里装了几十上百条的不会被锁死。

## 代码位置

| 文件 | 职责 |
| --- | --- |
| `ui/layout.js` | `BAG_*` 常量、`bagCellRect` / `bagChipRect` / `bagDetailRect` / `bagDetailBtnRect` |
| `render/sheet.js` | 三个子页的绘制，以及 `bagCellsOf` / `bagKeysOf` / `bagActionsOf` 三份共享数据源 |
| `ui/touch.js` | `handleBag` 一处处理整页点击，`runBagAction` 执行详情卡按钮 |
| `core/pond.js` | `bagCapOf` / `isBagFull`，抛竿时的上限拦截 |

**不要**在触摸层重抄格子顺序或按钮文案：渲染和触摸都从
`bagCellsOf` / `bagActionsOf` 取，加一种物品只改一处。
