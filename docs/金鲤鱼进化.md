# 金鲤鱼与化龙（M14）

> 对应版本 **v0.15.0 / saveVersion 7**
> 相关文件：`config/species.js`、`config/traits.js`、`config/economy.js`、
> `core/fish.js`、`core/dragon.js`、`core/pond.js`、`render/fishart.js`、`render/sell.js`

## 1. 产出：传奇鱼卵拆成两档

传奇鱼卵不再「必出小鲨鱼」：

| 产出 | 概率 | 说明 |
|---|---|---|
| 小鲨鱼 `reef_shark` | 90% | 不吃鱼饵、只吃缸里其他鱼，纯玩法鱼 |
| 金鲤鱼 `gold_koi` | 10% | 化龙线的起点，普通卵池与鱼塘都拿不到 |

- 金鲤鱼标了 `legendOnly: true`，图鉴「获取途径」直接写「传奇鱼卵 10%」。
- 它同时带 `secret: true, eggRate: 0`：不进常规权重池、不进 `secretPool`、
  不被 `avgSellOf` 重复计入期望。
- 普通 SSR 池（`shop.rarityPool('SSR')`）与鱼塘池（`pond.poolOf`）都排除它。

## 2. 词条：龙鳞

`config/traits.js` 新增第 7 条词条：

| 字段 | 值 |
|---|---|
| id | `dragon_scale` |
| 名称 | 龙鳞 |
| type | `dragon`（不参与任何加成计算，只作为化龙钥匙） |
| only | `['gold_koi']` |
| 卖价 | 走统一的 `1 + 0.06 × Σlv`，所以龙鳞也实打实涨价 |

- `rollTraits` 按 `only` 过滤词条池：普通鱼永远抽不到龙鳞。
- 金鲤鱼按 `traits.koiDragonRate = 0.55` **精确**决定是否带龙鳞：
  带 → 第一槽龙鳞；不带 → 龙鳞从池里摘掉。
  （若写成「保底一次 + 剩下随机」，实际概率会被第二槽顶到 67%，所以按精确概率实现。）

## 3. 进化：吞噬同族

规则一句话：**带龙鳞的金鲤鱼，吃一条金鲤鱼升一阶，三阶化龙。**

| 阶 `evo` | 名称 | 卖价/产出倍率 | 体型倍率 |
|---|---|---|---|
| 0 | 金鲤鱼 | 1.00 | 1.00 |
| 1 | 金纹鲤 | 1.60 | 1.10 |
| 2 | 蛟 | 2.50 | 1.22 |
| 3 | 真龙 | 4.20 | 1.38 |

实现要点（`core/dragon.js`）：

- `statusOf(state, id)` → `{ ok, reason, evo, max, stage, nextStage, prey, need }`
  - `reason`: `gone` / `not_koi` / `no_scale` / `no_prey` / `max`
- `preyListOf(state, id)` 的猎物条件：
  同种 `gold_koi`、`evo === 0`、不是自己；**仓库优先**，再按成长从低到高。
  允许吃仓库里的鱼，是为了不让「先腾鱼位」成为进化链上的一道额外手续。
- `devour(state, id)`：吃掉猎物 → `evo + 1` → 饱食 +20 → `stats.devoured +1`。
- 只吃 `evo 0` 的同族：已进化的鱼不会被误吃。

数值挂载点：

- `sellPriceOf` → `× evoMulOf(f)`
- `incomePerSecond` → `× evoMulOf(f)`
- `sizeOf` → `× evoSizeMulOf(f)`
- **`eggValueOf` / `matureValueOf` 不吃 evo**：卵价基准是鱼种属性，不能被某条鱼的状态抬高。

## 4. 界面：点鱼改成信息卡

M14 把「点鱼 → 头顶价签 → 直接卖」换成：

```
点鱼 → 选中光圈 + 屏幕底部信息卡
        卡上：名字 / 性别 / 身价 / 品质·阶段·成长·饱食 / 词条胶囊
        按钮：捞出到仓库  [ 吞噬 → 下一阶 ]（金鲤鱼带龙鳞才有）
```

- 鱼头顶不再画性别角标（性别挪进卡里）。
- 信息卡是屏幕坐标，放大 2× 也不会被裁；面板一开始升起就隐藏。
- 卡片上**没有直接卖鱼**：统一走「捞出 → 仓库 → 卖出」，少一次误触就少一条鱼。
- 「捞出」调 `pond.dumpToBag`：从缸里移除、坐标清零、进 `state.caught`、清选中。

## 5. 防误伤

- 鲨鱼（`core/predation.js`）**不会捕食带龙鳞的金鲤鱼**。普通金鲤鱼照吃。
